# Kairos Labs

> Ecossistema de soluções em tecnologia — DevPrint, AI & SaaS, Audio Tech, Blockchain.

Marca registrada no INPI — Processo nº 944610498 | Classe 42

## Stack

- **Next.js 15** (App Router + Turbopack)
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui**
- **Supabase** (PostgreSQL + Auth + RLS)
- **Vercel** (Hobby Tier — CI/CD automático)

## Setup local

\`\`\`bash
git clone https://github.com/CabPiz/kairos-labs.git
cd kairos-labs
npm install
cp .env.example .env.local
npm run dev
\`\`\`
